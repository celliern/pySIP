# Cookbook: pySIP by example

This cookbook contains a collection of complete examples that demonstrate how to
use pySIP. Topic-oriented examples will be added in the future.

Each example displays the notebook's stored Markdown, code, outputs, and figures
without executing any code during the documentation build. A download link on
each page provides the original Jupyter notebook for running or modifying the
example locally.

- [Matérn Gaussian process regression](examples/gaussian_process/regression_matern.md)
